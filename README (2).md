# Roshan Kumar Kumawat – Portfolio Website

A simple portfolio website for a B.Tech student, built with plain HTML, CSS and JavaScript. No installation needed.

## Files

| File | What it does |
|------|--------------|
| `index.html` | All five pages: Home, About me, Skills, Projects, Contact me |
| `style.css`  | Colours, fonts, layout, mobile and dark-mode styling |
| `script.js`  | Switches between pages and sends the contact form as an email |
| `README.md`  | These instructions |

Keep all files in the same folder.

## Run it

Double-click `index.html` to open it in your browser.

## Customise it

- **Text and links:** edit `index.html` (About me, Skills, Projects, Contact).
- **Colours:** change the values at the top of `style.css` (`--accent`, `--ink`, `--paper`).
- **Email address for the form:** change it in `script.js`.

## Put it online (free, GitHub Pages)

1. Create a repository on GitHub, for example `roshan.github.io`.
2. Upload all four files.
3. Go to Settings > Pages, choose the `main` branch and save.
4. Your site will appear at `https://roshan.github.io`.
